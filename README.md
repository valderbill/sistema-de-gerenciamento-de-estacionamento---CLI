# Sistema de Estacionamento

Este é um sistema simples de gerenciamento de estacionamento desenvolvido com a ajuda do GitHub Copilot CLI.

## Funcionalidades
- Registrar entradas e saídas de veículos
- Calcular o tempo de permanência
- Gerenciar vagas para carros, motos e PCD
- Exibir o status do estacionamento em tempo real

## Como rodar o projeto
1. Clone este repositório
2. Execute o arquivo `sistema_estacionamento.py` no Python
3. Interaja com o menu para registrar entradas, saídas e visualizar o status
